# Ultimate Learning System

An open, model-agnostic framework for transforming notes, PDFs, textbooks, and other source material into guided, mastery-based learning experiences.

## Vision

Ultimate Learning System is designed to help an AI teach rather than merely summarize. It should:

- analyze source material and identify prerequisites;
- reorder concepts into a learnable path;
- explain abstract ideas using concrete everyday analogies;
- generate instructional SVG diagrams instead of ASCII art;
- pause for understanding checks;
- diagnose misconceptions and change teaching strategy;
- advance only after evidence of mastery;
- produce structured, printable lesson notes and PDF-ready material;
- preserve a clear boundary between source content, verified enrichment, and inference.

## Project status

Early foundation. The first milestone defines the core skill contract, teaching loop, visual policy, and acceptance criteria before implementation-specific tooling is added.

## Core principle

> Build understanding before memorization. Use visuals and analogies to expose relationships, then use questions to verify that the learner can recall, explain, apply, and transfer the knowledge.
